# DivineNRF X3

DivineNRF X3 is an open-source wireless research device featuring an ESP32 chip, three NRF24L01 transmitters, and OLED display. This platform is made for wireless protocols analysis, embedded software development, and authorized security audits.

Features

* Dual-core ESP32 microcontroller
* Three 2.4 GHz NRF24L01 transceivers
* Built-in Wi-Fi and Bluetooth support
* OLED display for status and info display
* Portable and modular hardware
* Menu-driven user interface
* Open-source firmware
* Developed for education, development, and authorized wireless security research

Hardware

* ESP32 Dev Kit
* 3 × NRF24L01+ Transceivers
* 0.96" OLED Display (SSD1306)
* Buttons / Navigation
* Power (USB or Battery)
